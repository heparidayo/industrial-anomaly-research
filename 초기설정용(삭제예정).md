# industrial-anomaly-research

Windows PowerShell · Python 3.11 기준 초기 설정입니다.

## 1. 저장소 및 가상환경

```powershell
git clone https://github.com/heparidayo/industrial-anomaly-research.git
Set-Location industrial-anomaly-research

python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

이후 명령은 루트에서 실행하고, 가상환경에서 `.\.venv\Scripts\python.exe' 로 사용합티다.

## 2. 패키지 설치

NVIDIA GPU 사용 시 CUDA 12.8 빌드를

```powershell
python -m pip install torch==2.9.0 torchvision==0.24.0 --index-url https://download.pytorch.org/whl/cu128
python -m pip install -r requirements.txt
```

GPU가 없다면 CPU 빌드를 설치합니다.

```powershell
python -m pip install torch==2.9.0 torchvision==0.24.0 --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt
```

## 3. 폴더 및 데이터 준비

```powershell
New-Item -ItemType Directory -Force -Path data, outputs, experiments | Out-Null
```

[MVTec AD 공식 페이지](https://www.mvtec.com/research-teaching/datasets/mvtec-ad)에서 데이터를 받아 `bottle` 폴더를 다음 위치에 배치합니다.

```text
data/raw/mvtec_ad/bottle/
├── train/good/
├── test/good/
├── test/<defect_type>/
└── ground_truth/<defect_type>/
```
